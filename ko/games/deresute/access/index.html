DERESUTE · 문제 해결

렉·튕김 해결 방법

Deresute는 일부 기기에서 튕기기 쉬운 것으로 알려져 있습니다. 원인과 해결 방법, 그리고 플레이 전에 꼭 해 둘 준비를 정리했습니다.

먼저 할 일: Namco ID 등록

플레이하려면 Namco ID(반다이남코 계정)가 필요하며, 기기 변경 시 데이터 이전에도 사용됩니다. 설치 직후 바로 등록하세요. 등록하지 않은 상태에서 기기가 고장 나거나 분실되면 그동안의 진행 상황을 복구할 수 없습니다.

튕김·끊김 해결 방법

  1. 1라이브 연출을 2D 모드로 바꿉니다. 3D보다 훨씬 가벼워서 저사양 기기에서 눈에 띄게 안정적입니다.
  2. 2게임을 실행하기 전에 백그라운드에서 돌아가는 다른 앱을 종료합니다. 특히 SNS 앱과 브라우저가 메모리를 많이 차지합니다.
  3. 3플레이 전에 기기를 재부팅합니다. 오래 연속으로 플레이한 뒤 불안정해지는 경우 특히 효과적입니다.
  4. 4그래도 튕긴다면 저장 공간의 여유 용량을 확인합니다. 공간이 부족하면 캐시 쓰기에 실패하기 쉬워집니다.
3D 모드를 고집할 필요는 없습니다: 라이브 연출은 3D가 더 화려하지만, 점수나 플레이 자체에는 영향이 없습니다. 안정성을 우선한다면 2D 모드로 고정해도 전혀 문제없습니다.
