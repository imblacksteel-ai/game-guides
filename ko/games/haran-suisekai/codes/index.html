기프트 코드

현재 사용 가능한 모든 코드와 입력 방법입니다. 코드는 예고 없이 만료될 수 있으니, 여기서 보이는 즉시 입력하고 미루지 마세요.

코드만료일
FLOTDISCORD2026없음
새 코드는 어디서 발표되나요: 공식 페이스북과 X 계정(@playWWW_JP)에서 가장 먼저 발표되며, 보통 마일스톤이나 점검 시점에 맞춰 배포됩니다. 보상은 게임 내 메일로 도착하고, 수령에는 선장 레벨 9가 필요합니다 — 코드가 필요해지기 전에 미리 레벨을 올려두세요.

입력 방법 (iOS)

  1. 1홈 화면 왼쪽 위 캐릭터 아이콘을 탭합니다.
  2. 2설정 → 유저 센터로 이동합니다.
  3. 3유저 ID를 복사합니다.
  4. 4기프트 코드 입력 페이지에서 ID와 코드를 입력해 교환합니다.

입력 방법 (Android)

  1. 1홈 화면 왼쪽 위 캐릭터 아이콘을 탭합니다.
  2. 2"기프트 코드"를 선택합니다.
  3. 3코드를 입력해 교환합니다.

코드가 가끔 안 먹히는 이유는?

가장 흔한 이유는 두 가지입니다: 코드가 이미 만료되었거나, 해당 계정에서 이미 사용된 경우입니다 — 코드는 기기 단위가 아니라 계정당 1회만 사용할 수 있습니다. 오타도 확인해 보세요. 코드는 대소문자를 구분합니다.

얼마나 자주 확인해야 하나요: 주 1회면 충분합니다. 새 코드는 보통 마일스톤이나 점검 시점에 맞춰 나오며, 새 코드가 나오면 하루 안에 이 페이지에 반영하고, 더 이상 작동하지 않으면 바로 제거합니다.
