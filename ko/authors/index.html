운영 방식

Kouryaku Lab은 대규모 편집팀이나 공개된 개인 필명 없이 독립적으로 운영됩니다. 개인정보 보호를 위해 이름이나 사진을 공개하지 않기로 했지만, 그렇다고 책임을 지지 않는 것은 아닙니다 — 모든 가이드에는 출처가 명시되어 있고, 모든 메인 가이드 상단에는 최종 업데이트 날짜가 표시되며, 언제든 문의 페이지를 통해 연락하실 수 있습니다.

배경

이 사이트는 일본에서는 인기가 많지만 공식 글로벌 출시나 영어 로컬라이징이 전혀 이루어지지 않은 모바일 게임에 집중합니다. 다른 영어 공략 사이트를 다시 쓴 것이 아니라, 일본어 자료와 게임 내 공식 정보, 신뢰할 수 있는 커뮤니티 위키를 직접 조사해 작성하며, 게임의 접근 제한이 허용하는 범위에서는 실제 플레이를 통해서도 검증합니다. 각 가이드가 정확히 어떻게 제작되고 검증되는지는 편집 방침을 참고하세요.

필명 없이도 지키는 책임

익명이라고 해서 추적이 불가능한 것은 아닙니다. 이 사이트의 모든 페이지는 공개 GitHub 저장소에서 버전 관리되며, 오류 제보는 비공개 이메일이 아닌 공개 GitHub 이슈로 처리하고, 자료 수집과 검증 과정 전체를 신뢰에만 맡기지 않고 문서로 공개하고 있습니다.

질문이나 오류 제보는 문의를 확인하세요.
