Mods: Installing and Popular Picks

How Unciv's GitHub-based mod browser works, how to install mods, and the most-starred mods right now.

01

Conclusion

Unciv mods live on GitHub. The in-game mod browser searches for repositories tagged unciv-mod (Github.kt), and the categories you see are GitHub topics such as unciv-mod-rulesets (ModCategories.json).

Below are the most-starred mods on GitHub right now, with their category and last update — stars aren't the same as quality, but they're a public, checkable signal of what players use.

An analysis-based guide: this guide is based on our analysis of Unciv's mod-browser code and public GitHub repository data. It describes what the data shows and is not a guarantee of results.
02

How to Install a Mod

  1. 1From the main menu, open Mods. The list on the left comes from GitHub.
  2. 2Pick a mod and download it. If a mod isn't listed, use Download mod from URL with its GitHub link.
  3. 3Rulesets are chosen as the Base Ruleset when you start a new game; expansions are ticked under Extension mods.
  4. 4Graphics and audio mods can be set as a permanent audiovisual mod so they apply to every game.

Mod Categories

Category (GitHub topic)What it is
Rulesets (unciv-mod-rulesets)A complete ruleset you play instead of Civ V Gods & Kings — total conversions and overhauls.
Expansions (unciv-mod-expansions)Adds civilizations, units or buildings on top of a base ruleset.
Graphics (unciv-mod-graphics)Tilesets, unit sprites, leader portraits.
Audio (unciv-mod-audio)Music and sounds.
Maps (unciv-mod-maps)Pre-made maps.
Fun (unciv-mod-fun)Joke and sandbox mods.
Mods of mods (unciv-mod-modsofmods)Add-ons for another mod.

FAQ

Can I use an expansion with any base ruleset?

Not always. If a base ruleset isn't compatible with the extension mods you picked, the game disables them.

Are mods safe?

Unciv mods are data files (rulesets, images, sounds) downloaded from GitHub. Still, they're community-made — read the mod's page before using it.

Why isn't a mod in the in-game list?

The browser only finds repositories tagged unciv-mod. Use Download mod from URL for others.
