What Unciv Is

Unciv is a free, open-source remake of Civilization V for Android and desktop. Its own store description calls it light, small, ad-free and completely free; the code is on GitHub under the MPL-2.0 license.

Because the game is open source, every number on these pages comes straight from its data files rather than from memory or old wikis. The main built-in ruleset mirrors Civ V's Gods & Kings expansion, and the unit file itself notes its values follow the Civilization wiki and CivFanatics.

An analysis-based guide: this guide is based on our analysis of Unciv's own data files and source code. It describes what the data shows and is not a guarantee of results.

FAQ

Is Unciv the same as Civilization V?

It's an independent remake that follows Civ V's rules and numbers closely, but it's its own game with its own updates. Treat Civ V guides as a starting point, not gospel.

Are these numbers current?

They come from the game's source at the commit of 2026-10-02. Unciv updates often, so a value may change in a later version.

Do mods change this?

Yes. These pages cover the built-in Gods & Kings ruleset. Mods can add civilizations and change any number.

Is Japanese available in the game?

Yes — the game ships with a Japanese translation, and the Japanese versions of these pages use its official names.
