Multiplayer: Playing Online

Starting an online game step by step, and hosting your own server when the default one is busy.

01

Conclusion

Unciv's multiplayer works by uploading and downloading the save file each turn. Everyone must be on the same multiplayer server; the host starts the game with the other players' user IDs and sends them the game ID.

According to the official docs, the default server is a free Dropbox account shared by many players, so it isn't always reachable. For reliable games you can host your own server with the official UncivServer.jar.

An analysis-based guide: this guide is based on our analysis of Unciv's official multiplayer documentation. It describes what the data shows and is not a guarantee of results.
02

How to Start a Game

  1. 1Everyone checks they use the same server: Main Menu → Options → Multiplayer.
  2. 2Each player copies their user ID (Main Menu → Multiplayer → Copy user ID) and sends it to the host. You can also add them to your Friends list.
  3. 3The host goes to Start new game, ticks Online Multiplayer, adds human players and enters their user IDs, then presses Start game!
  4. 4The game ID is copied to the host's clipboard automatically (or use Multiplayer → Copy game ID). Send it to the others.
  5. 5The other players open Multiplayer → Add multiplayer game, enter the game ID, and join from that screen.
03

Hosting Your Own Server

  1. 1Install a Java JDK and download the latest UncivServer.jar from the Unciv releases page on GitHub.
  2. 2Next to the jar, create a folder named MultiplayerFiles, open a terminal there and run java -jar UncivServer.jar.
  3. 3Test it on the same computer: in Unciv, Options → Multiplayer, set the server address to http://localhost:8080 and check the connection.
  4. 4For players outside your network, forward the server's port (default 8080) on your router and use http://<your public IP>:<port>.
  5. 5Every player sets the same server address. Devices on different servers can't play together.
Good to know: the server is simple file storage over HTTP. Options are -p (port) and -f (folder); files aren't cleaned up when a game ends. If your public IP changes, you'll need to update it or use a dynamic DNS service.
04

FAQ

Why can't I connect to the default server?

The docs say the default Dropbox-based server is shared by many players and has hit its limits several times. Hosting your own server is the official workaround.

Are there community servers?

The docs list some community-run servers, with a warning that they're unofficial, may go offline and lose saves, and may collect data. Use them only if you accept that.

Do I need to be online at the same time?

No. Because the game passes the save file around, players can take turns whenever they're available.
