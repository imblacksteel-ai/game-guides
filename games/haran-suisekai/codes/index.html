Where new codes get announced: the official Facebook and X account (@playWWW_JP) posts codes first, usually tied to milestones or maintenance. Rewards arrive by in-game mail, and claiming them requires Captain Level 9 — get there before you expect to need a code.

How to Redeem (iOS)

  1. 1Tap the character icon in the top-left of the home screen.
  2. 2Open Settings → User Center.
  3. 3Copy your User ID.
  4. 4Enter your ID and the code on the gift code redemption page.

How to Redeem (Android)

  1. 1Tap the character icon in the top-left of the home screen.
  2. 2Select "Gift Code."
  3. 3Enter the code to redeem.

Why does a code sometimes fail to redeem?

The two most common reasons: the code has expired, or it's already been claimed on your account — each code is one-time-use per account, not per device. Double-check for typos too; codes are case-sensitive.

How often to check: Once a week is enough. New codes are usually tied to milestones or maintenance, and we update this page within a day of any new code going live — and remove it as soon as it stops working.
