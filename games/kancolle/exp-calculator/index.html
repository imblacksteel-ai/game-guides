Where do I find base EXP? It's on the battle result screen, labelled 基本経験値 (kihon keikenchi, "base experience"). Since the 2018 Phase 2 update it depends on the enemy fleet you fought, not just the map, so the same node can give different values — use the number from the battle you're actually repeating.

How it's calculated

EXP per battle = base EXP × rank multiplier × 1.5 if flagship × 2 if MVP. An E rank has no MVP. The best case, a flagship MVP with an S rank, earns 3.6× base EXP.

Ships stop at Lv99 until you use a Marriage ring (ケッコンカッコカリ). The ring itself takes the ship to Lv100 with no extra EXP, and married ships can then keep levelling to the current cap of Lv188. This calculator doesn't include the training cruiser (CT) bonus, and in-game rounding can shift the totals by a few points.
