Event Ship Locks (Tags) Explained

Sortie a ship into the wrong event map and it can be locked out of the one you actually need. Here's how tags work, when they matter, and how to plan around them.

01

Conclusion

In many events, a ship gets a tag (出撃識別札, Shutsugeki Shikibetsu Fuda; players just say 札, fuda) for the first event map it sorties into. The tag can't be changed or removed until the event ends.

On Normal and Hard, a tagged ship can't sortie into maps that use a different tag. On Easy and Casual, you can ignore the restriction.

So the one thing to avoid is sending your best ships into an early map on Normal/Hard and then finding them locked out of the final map.

An analysis-based guide: this guide is based on our analysis of the sortie-restriction rules on the Japanese KanColle wiki. It describes what the data shows and is not a guarantee of results.
02

How Tags Work

  • The tag is the one for the first tag-giving map a ship sorties into. If a ship already has a tag, sortieing elsewhere doesn't change it.
  • Tags are applied on every difficulty — what changes is whether they restrict you.
  • Hard and Normal: a tagged ship can't sortie into event maps that use a different tag.
  • Easy and Casual: tagged ships can sortie anywhere. But being allowed to sortie isn't the same as getting the route you want — some maps still need a fleet with matching tags for routing, even on lower difficulties.
  • Tags are per individual ship. An untagged duplicate of the same ship can go to a different map.
  • Regular maps, expeditions and exercises ignore tags completely.
  • In some events the restrictions are lifted once every map is cleared, even on Normal/Hard.
03

Finding Tagged Ships

During an event, the ship list in Organize (編成, Hensei) gets an extra filter at the right end of the ship-type filters. Click it to cycle 全艦艇 (all ships) → 作戦参加 (Sakusen Sanka, tagged / in the operation) → 待機中 (Taikichū, untagged / on standby).

04

How to Plan Around Tags

  1. 1Before your first sortie, check which maps share a tag. The event's map guide usually lists them.
  2. 2Decide which map needs your strongest ships — usually the last one — and keep them out of earlier maps that use a different tag.
  3. 3Clear early maps with the ships you can spare. Untagged duplicates are useful here.
  4. 4If you're not sure you can finish on Normal/Hard, playing on Easy or Casual removes the problem entirely.
05

FAQ

Can I remove a tag?

No. Tags can't be changed or removed by any means until the event ends.

Do tags affect regular maps?

No — only event maps. Regular maps, expeditions and exercises work as usual.

I'm on Easy. Do tags matter at all?

They're still applied, and occasionally a route needs matching tags, but they won't block you from sortieing.

Do tags carry over to the next event?

No — restrictions are lifted when the event ends.
