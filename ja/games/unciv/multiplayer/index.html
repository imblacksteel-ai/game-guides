UNCIV ・ マルチプレイ

マルチプレイのやり方

オンライン対戦の始め方と、標準サーバーが混んでいるときに自分のサーバーを立てる方法。

01

結論

Uncivのマルチプレイは、毎ターンのセーブファイルをアップロード・ダウンロードする仕組み。全員が同じマルチプレイサーバーを使う必要があり、ホストが他のプレイヤーのユーザーIDでゲームを作り、ゲームIDを送る。

公式ドキュメントによると、標準のサーバーは多くのプレイヤーが共有する無料のDropboxアカウントなので、つながらないことがある。安定して遊ぶなら、公式のUncivServer.jarで自分のサーバーを立てる方法がある。

分析に基づく記事です：この記事はUncivの公式マルチプレイドキュメントを分析してまとめたもの。データ上の傾向を示すもので、結果を保証するものではない。
02

ゲームの始め方

  1. 1全員が同じサーバーを使っているか確認する：メインメニュー → 設定 → マルチプレイ。
  2. 2各プレイヤーがユーザーIDをコピーして（メインメニュー → マルチプレイ → ユーザーIDをコピー）ホストに送る。フレンドリストに登録しておくこともできる。
  3. 3ホストは新しくゲームを始めるでオンラインマルチプレイにチェックを入れ、人間のプレイヤーを追加してユーザーIDを入力し、ゲーム開始を押す。
  4. 4ゲームIDは自動でホストのクリップボードにコピーされる（マルチプレイ → ゲームIDをコピーでも取得できる）。他のプレイヤーに送る。
  5. 5他のプレイヤーはマルチプレイ → マルチプレイゲームを追加でゲームIDを入力し、その画面から参加する。
03

自分のサーバーを立てる

  1. 1Java JDKをインストールし、GitHubのUncivのリリースページから最新のUncivServer.jarをダウンロードする。
  2. 2jarと同じ場所にMultiplayerFilesというフォルダを作り、そこでターミナルを開いて java -jar UncivServer.jar を実行する。
  3. 3同じパソコンで確認する。Uncivの設定 → マルチプレイでサーバーのアドレスを http://localhost:8080 にして、接続を確認する。
  4. 4外部のプレイヤー向けには、ルーターでサーバーのポート（標準8080）を転送し、http://（グローバルIP）:（ポート） を使う。
  5. 5全員が同じサーバーのアドレスを設定する。違うサーバーの端末同士では一緒に遊べない。
補足：サーバーはHTTPでファイルを置くだけのシンプルなもの。オプションは -p（ポート）と -f（フォルダ）。ゲームが終わってもファイルは自動で消えない。グローバルIPが変わる環境では、その都度更新するかダイナミックDNSを使う。
04

FAQ

標準のサーバーにつながらないのはなぜ？

公式ドキュメントによると、Dropboxを使う標準サーバーは多くのプレイヤーが共有していて、何度も上限に達している。自分でサーバーを立てるのが公式の対処法。

コミュニティのサーバーはある？

公式ドキュメントにはコミュニティ運営のサーバーも載っているが、非公式で、停止したりセーブが消えたりすることがあり、データを収集する可能性もあると注意書きがある。それを受け入れられる場合だけ使おう。

同時にオンラインでいる必要はある？

ない。セーブファイルを回す仕組みなので、各自が都合の良いときに手番を進められる。
