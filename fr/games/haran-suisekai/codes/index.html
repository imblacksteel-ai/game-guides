Où sont annoncés les nouveaux codes : le compte Facebook et X officiel (@playWWW_JP) publie les codes en premier, généralement liés à des jalons ou à la maintenance. Les récompenses arrivent par mail en jeu, et leur récupération nécessite le niveau de capitaine 9 — atteignez-le avant d'avoir besoin d'un code.

Comment l'utiliser (iOS)

  1. 1Appuyez sur l'icône du personnage en haut à gauche de l'écran d'accueil.
  2. 2Ouvrez Paramètres → Centre utilisateur.
  3. 3Copiez votre identifiant utilisateur.
  4. 4Saisissez votre identifiant et le code sur la page de récupération des codes cadeaux.

Comment l'utiliser (Android)

  1. 1Appuyez sur l'icône du personnage en haut à gauche de l'écran d'accueil.
  2. 2Sélectionnez « Code cadeau ».
  3. 3Saisissez le code pour l'utiliser.

Pourquoi un code échoue-t-il parfois ?

Les deux raisons les plus courantes : le code a expiré, ou il a déjà été utilisé sur votre compte — chaque code est à usage unique par compte, pas par appareil. Vérifiez aussi les fautes de frappe ; les codes sont sensibles à la casse.

À quelle fréquence vérifier : une fois par semaine suffit. Les nouveaux codes sont généralement liés à des jalons ou à la maintenance — nous mettons à jour cette page dans la journée suivant l'annonce d'un nouveau code, et le retirons dès qu'il cesse de fonctionner.
