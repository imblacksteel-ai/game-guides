How to Reach Us

This site is independently run (see Authors) and doesn't have a support inbox. The fastest way to reach us is to open an issue on the GitHub repository.

What to Include

  • Corrections — the guide page's URL, what's wrong, and a source if you have one. See the Editorial Policy for how we verify reports.
  • Outdated info — what changed in the game and when, if known.
  • Suggestions — a topic or game you'd like covered isn't a bug, but we still read every one.

We read every issue and aim to fix confirmed errors within a few days. This isn't a guaranteed-response support channel, so please don't send anything time-sensitive.
