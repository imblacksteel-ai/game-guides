概述

Kouryaku Lab（以下简称"本站"）是一个免费提供的非官方游戏攻略与计算工具站点。本页说明您访问本站时会收集哪些信息，以及广告与 Cookie 的使用方式。

我们收集的信息

使用本站无需注册账号，我们不会直接收集您的姓名、邮箱等个人信息。本站托管于 GitHub Pages，并通过 Cloudflare 分发。出于安全与性能考虑，这两项服务可能会自动记录 IP 地址、浏览器类型、访问页面等技术信息，具体遵循各自的隐私政策。

Cookie 与广告

本站可能展示由 Google AdSense 提供的广告。Google 及其合作伙伴可能使用 Cookie（包括 DoubleClick DART Cookie）根据您在本站及其他网站的访问记录投放广告。您可以前往 Google 广告设置关闭个性化广告，详情参见 aboutads.info。

本站字体通过 Google Fonts 加载，加载过程中 IP 地址等请求信息可能依据 Google 隐私政策被记录。

第三方链接

攻略页面会链接到外部资料来源（游戏 Wiki、新闻网站、官方页面等）以标注出处。本站不对这些外部网站的内容或隐私做法负责。

儿童隐私

本站不面向13岁以下儿童，也不会故意收集儿童的个人信息。

政策变更

随着站点功能更新（例如新增广告），本政策可能会调整，届时会更新本页顶部的修改日期。
