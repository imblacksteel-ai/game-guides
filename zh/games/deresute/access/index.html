卡顿、闪退的解决方法

Deresute在部分设备上容易闪退。这里整理了原因、解决方法，以及开始游玩前应当先完成的准备。

首先要做：注册Namco ID

游玩需要Namco ID（万代南梦宫的账号），更换设备时的数据继承也要用到它。请在安装后立即注册。如果在注册前设备损坏或丢失，之前的游戏进度将无法恢复。

闪退、卡顿的解决方法

  1. 1将演出画面切换为2D模式。它比3D轻量得多，在低配设备上明显更稳定。
  2. 2启动游戏前关闭后台运行的其他应用。社交应用和浏览器尤其占用内存。
  3. 3游玩前重启设备。长时间连续游玩后容易变得不稳定时尤其有效。
  4. 4如果仍然闪退，请检查存储空间的剩余容量。空间不足时，缓存写入更容易失败。
不必执着于3D模式：3D演出更华丽，但对分数和游玩本身没有影响。如果优先考虑稳定性，固定使用2D模式完全没有问题。
