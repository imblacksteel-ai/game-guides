本站的运营方式

Kouryaku Lab 由个人独立维护，没有大型编辑团队，也不公开具名署名。出于隐私考虑，我们选择不在此公开姓名或照片——但本站依然完全可追责：每篇攻略都列出信息来源，每个主攻略页面都显示最后更新时间，您也可以随时通过联系页面与我们取得联系。

背景

本站专注于在日本很受欢迎、但从未推出官方全球版或英文本地化的手机游戏。攻略内容直接调研自日文一手资料、游戏内官方信息和公认可靠的社区 Wiki，而非改写自其他英文攻略站，并在游戏访问限制允许的范围内通过实机游玩进行核实。各篇攻略具体是如何制作和核实的，请参见编辑方针。

没有署名，依然可追责

匿名不等于无法追溯。本站所有页面都通过公开的 GitHub 仓库进行版本管理，勘误以公开的 GitHub Issue 形式处理，而非私下邮件，资料来源与核实流程也都有据可查，而非仅凭信任。

如有疑问或需要勘误，请查看联系我们。

本站为非官方粉丝制作内容。
