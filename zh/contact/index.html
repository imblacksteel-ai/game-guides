如何联系我们

本站由个人独立运营（参见关于作者），没有专门的客服邮箱。最快的联系方式是在 GitHub 仓库提交 Issue。

请附上以下信息

  • 勘误——攻略页面的 URL、具体错误之处，以及信息来源（如有）。核实方式请参见编辑方针。
  • 过时信息——游戏中发生了什么变化，以及大致时间（如果知道的话）。
  • 建议——希望我们收录的游戏或主题不算错误报告，但我们同样会认真查看每一条。

我们会查看每一条 Issue，并力争在确认问题后的几天内完成修正。这并非保证及时回复的客服渠道，请勿发送时效性极强的内容。

本站为非官方粉丝制作内容。
