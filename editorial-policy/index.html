What This Page Covers

This page explains exactly how Kouryaku Lab guides are researched, sourced, verified, and kept up to date. For who runs the site, see Authors.

Sources We Use

  • Official in-game information — patch notes, in-game text, and developer announcements, where available.
  • Community wikis and guides — established Japanese wikis and creator write-ups, listed under "Sources" at the bottom of every guide page.
  • Game master data — for numbers-heavy pages such as the KanColle tools, stats come from public datasets extracted from the game's own master data rather than being copied by hand from other guide sites.

How We Verify Content

Where community sources disagree with each other — a common problem for games with no official English documentation — we cross-check against more than one source before publishing. If something can't be confirmed with reasonable confidence, we either leave it out or say plainly in the guide that it's unconfirmed, rather than stating it as fact.

How We Keep Guides Current

Every top-level game guide shows an "Updated" date near the top. When a game update changes strategy — new recipes, rebalanced stats, a new gacha banner, a new area — we update the affected guide rather than leaving outdated advice live. Time-sensitive pages, like gift code lists, show the date they were last checked, so you can judge how current they are.

Analysis-Based Guides

Some guides — such as map strategies and recommended fleets or teams — are built by analyzing published game data: routing rules, stat tables, master data and community-maintained datasets. These pages say so near the top and link their sources. They describe what the data favors and are not a guarantee of results; game updates can change the underlying data.

Corrections

If something on this site is wrong, outdated, or unclear, see Contact to report it. We read every report and aim to fix confirmed errors within a few days.
