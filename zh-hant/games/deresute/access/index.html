DERESUTE · 問題排查

卡頓、閃退的解決方法

Deresute在部分裝置上容易閃退。這裡整理了原因、解決方法，以及開始遊玩前應當先完成的準備。

首先要做：註冊Namco ID

遊玩需要Namco ID（萬代南夢宮的賬號），更換裝置時的資料繼承也要用到它。請在安裝後立即註冊。如果在註冊前裝置損壞或丟失，之前的遊戲進度將無法恢復。

閃退、卡頓的解決方法

  1. 1將演出畫面切換為2D模式。它比3D輕量得多，在低配裝置上明顯更穩定。
  2. 2啟動遊戲前關閉後臺執行的其他應用。社交應用和瀏覽器尤其佔用記憶體。
  3. 3遊玩前重啟裝置。長時間連續遊玩後容易變得不穩定時尤其有效。
  4. 4如果仍然閃退，請檢查儲存空間的剩餘容量。空間不足時，快取寫入更容易失敗。
不必執著於3D模式：3D演出更華麗，但對分數和遊玩本身沒有影響。如果優先考慮穩定性，固定使用2D模式完全沒有問題。
