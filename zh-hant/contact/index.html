如何聯絡我們

本站由個人獨立運營（參見關於作者），沒有專門的客服郵箱。最快的聯絡方式是在 GitHub 倉庫提交 Issue。

請附上以下資訊

  • 勘誤——攻略頁面的 URL、具體錯誤之處，以及資訊來源（如有）。核實方式請參見編輯方針。
  • 過時資訊——遊戲中發生了什麼變化，以及大致時間（如果知道的話）。
  • 建議——希望我們收錄的遊戲或主題不算錯誤報告，但我們同樣會認真檢視每一條。

我們會檢視每一條 Issue，併力爭在確認問題後的幾天內完成修正。這並非保證及時回覆的客服渠道，請勿傳送時效性極強的內容。

本站為非官方粉絲製作內容。
