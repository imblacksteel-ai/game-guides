本站的運營方式

Kouryaku Lab 由個人獨立維護，沒有大型編輯團隊，也不公開具名署名。出於隱私考慮，我們選擇不在此公開姓名或照片——但本站依然完全可追責：每篇攻略都列出資訊來源，每個主攻略頁面都顯示最後更新時間，您也可以隨時通過聯絡頁面與我們取得聯絡。

背景

本站專注於在日本很受歡迎、但從未推出官方全球版或英文在地化的手機遊戲。攻略內容直接調研自日文一手資料、遊戲內官方資訊和公認可靠的社群 Wiki，而非改寫自其他英文攻略站，並在遊戲訪問限制允許的範圍內通過實機遊玩進行核實。各篇攻略具體是如何製作和核實的，請參見編輯方針。

沒有署名，依然可追責

匿名不等於無法追溯。本站所有頁面都通過公開的 GitHub 倉庫進行版本管理，勘誤以公開的 GitHub Issue 形式處理，而非私下郵件，資料來源與核實流程也都有據可查，而非僅憑信任。

如有疑問或需要勘誤，請檢視聯絡我們。

本站為非官方粉絲製作內容。
