概述

Kouryaku Lab（以下簡稱"本站"）是一個免費提供的非官方遊戲攻略與計算工具站點。本頁說明您訪問本站時會收集哪些資訊，以及廣告與 Cookie 的使用方式。

我們收集的資訊

使用本站無需註冊賬號，我們不會直接收集您的姓名、郵箱等個人資訊。本站託管於 GitHub Pages，並通過 Cloudflare 分發。出於安全與效能考慮，這兩項服務可能會自動記錄 IP 地址、瀏覽器型別、訪問頁面等技術資訊，具體遵循各自的隱私政策。

Cookie 與廣告

本站可能展示由 Google AdSense 提供的廣告。Google 及其合作夥伴可能使用 Cookie（包括 DoubleClick DART Cookie）根據您在本站及其他網站的訪問記錄投放廣告。您可以前往 Google 廣告設定關閉個性化廣告，詳情參見 aboutads.info。

本站字型由本站自身伺服器提供，不會向 Google Fonts 等任何第三方字型服務傳送請求。

資料分析

本站使用 Google Analytics 來了解訪問者如何使用本站，例如哪些頁面和語言版本最常被閱讀。Google Analytics 會使用 Cookie，並可能收集您的大致位置、裝置型別以及在本站的瀏覽行為等資料。如需選擇退出，可使用 Google Analytics(分析)選擇停用瀏覽器外掛，詳情請參見 Google 隱私政策。

第三方連結

攻略頁面會連結到外部資料來源（遊戲 Wiki、新聞網站、官方頁面等）以標註出處。本站不對這些外部網站的內容或隱私做法負責。

兒童隱私

本站不面向13歲以下兒童，也不會故意收集兒童的個人資訊。

政策變更

隨著站點功能更新（例如新增廣告），本政策可能會調整，屆時會更新本頁頂部的修改日期。

聯絡我們
