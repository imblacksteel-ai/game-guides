DERESUTE · FEHLERBEHEBUNG

Abstürze und Ruckeln beheben

Deresute ist dafür bekannt, auf manchen Geräten abzustürzen. Hier stehen die Ursachen, die Lösungen und der eine Einrichtungsschritt, den du vor dem Spielen erledigen solltest.

Zuerst erledigen: Namco ID anlegen

Zum Spielen brauchst du eine Namco ID (das Kontosystem von Bandai Namco); über sie überträgst du deinen Fortschritt auch auf ein neues Gerät. Lege sie direkt nach der Installation an – geht dein Handy vorher kaputt oder verloren, lässt sich dein Fortschritt nicht wiederherstellen.

Abstürze und Ruckler beheben

  1. 1Stelle Live-Auftritte auf den 2D-Modus um. Er ist deutlich leichter als 3D und auf schwächeren Geräten merklich stabiler.
  2. 2Schließe vor dem Start andere Apps, die im Hintergrund laufen – Social-Media-Apps und Browser belegen besonders viel Speicher.
  3. 3Starte dein Gerät vor dem Spielen neu, vor allem wenn das Spiel nach langen Sessions instabil wird.
  4. 4Stürzt es trotzdem ab, prüfe den freien Speicherplatz. Wird er knapp, schlagen die Cache-Schreibvorgänge des Spiels häufiger fehl.
Im 2D-Modus verpasst du nichts: 3D-Lives sehen spektakulärer aus, haben aber keinen Einfluss auf Punktzahl oder Gameplay. Das Spiel für mehr Stabilität fest auf 2D zu stellen, ist völlig in Ordnung.
