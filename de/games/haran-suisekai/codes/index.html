Gutscheincodes

Jeder aktive Code und wie du ihn einlöst. Codes laufen ohne Vorwarnung ab, also löse sie ein, sobald du sie hier siehst — warte nicht.

CodeLäuft ab
FLOTDISCORD2026Kein Ablauf
Wo neue Codes angekündigt werden: der offizielle Facebook- und X-Account (@playWWW_JP) postet Codes zuerst, meist im Zusammenhang mit Meilensteinen oder Wartungsarbeiten. Belohnungen kommen per Spielmail, und zum Einlösen brauchst du Kapitänslevel 9 — erreiche das, bevor du einen Code brauchst.

Einlösen (iOS)

  1. 1Tippe auf das Charaktersymbol oben links auf dem Startbildschirm.
  2. 2Öffne Einstellungen → Benutzerzentrum.
  3. 3Kopiere deine Benutzer-ID.
  4. 4Gib deine ID und den Code auf der Einlöseseite für Gutscheincodes ein.

Einlösen (Android)

  1. 1Tippe auf das Charaktersymbol oben links auf dem Startbildschirm.
  2. 2Wähle "Gutscheincode".
  3. 3Gib den Code zum Einlösen ein.

Warum lässt sich ein Code manchmal nicht einlösen?

Die zwei häufigsten Gründe: der Code ist abgelaufen, oder er wurde auf deinem Account bereits eingelöst — jeder Code ist pro Account einmal nutzbar, nicht pro Gerät. Prüfe auch auf Tippfehler; bei Codes wird zwischen Groß- und Kleinschreibung unterschieden.
